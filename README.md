## 🚀 Key Features

- 💎 **Modern Dark-Mode Aesthetic**: Handcrafted visual styling with glassmorphism, accent glow effects, and fluid Framer Motion animations.
- 🧮 **Interactive Project Cost & Scope Estimator**: Dynamic real-time calculation of project timeline and budget based on platform type, UI/UX complexity, back-end features, and delivery rush speed.
- 🧠 **AI Models Showcase**: Interactive deep-dive into custom neural routers, computer vision engines, and WebAssembly physics vectors.
- 📁 **Interactive 3D Folder Section**: Sleek expandable folder UI representing different services, repositories, and technical deliverables.
- 🎯 **Radar Skill Proficiency Chart**: Mathematical SVG canvas displaying multi-axis mastery across React, TypeScript, Cloud, DevOps, and UI/UX.
- 💬 **Testimonial Carousel & Review System**: Interactive client feedback slider with verified metrics and success stories.
- 💼 **Careers & Freelance Hub**: Filterable role openings and an instant application submission modal.
- 📱 **Multi-Channel Contact Integration**: Integrated contact form, Calendly booking integration, and floating direct WhatsApp connect button.
- 🔍 **SEO & Performance Optimized**: 100/100 Lighthouse-ready architecture with automated `sitemap.ts`, `robots.ts`, OpenGraph metadata, and streaming edge components.

## ⚡ Getting Started

### Prerequisites
- **Node.js**: v18.18.0 or later
- **Package Manager**: `npm`, `pnpm`, `yarn`, or `bun`

### 1. Clone the Repository
```bash
git clone https://github.com/AnshCoderRepo/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
```bash
npm run build
npm run start
```
